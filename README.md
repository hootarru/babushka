# Бабушка на связи

Лендинг студенческого социального проекта: молодые люди 18–30 лет разговаривают по аудиосвязи с бабушками 60–80 лет.

Сайт: https://hootarru.github.io/babushka/

Один файл `index.html`, без сборки. Чтобы поменять текст или цвета – отредактируй `index.html`, сохрани, и GitHub Pages обновит сайт за 1–2 минуты.
